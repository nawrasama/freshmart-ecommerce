🛒 FreshMart - Online Grocery Store

A modern, responsive online grocery store built with HTML, CSS, JavaScript, and Node.js.

✨ Features

🛍️ Shopping Experience
- Product Catalog - Beautiful grid layout with product images and details
- Smart Filtering - Filter by availability, offers, and categories
- Search Functionality - Real-time product search
- Product Details - Detailed product views with zoom capability

🛒 Cart & Checkout
- Shopping Cart - Add/remove items with quantity controls
- Real-time Updates - Live cart total and item count
- Stock Validation - Prevents over-ordering out-of-stock items
- Secure Checkout - User authentication required for purchases

👤 User Management
- User Registration - Simple sign-up process
- Login System - Secure authentication
- Session Management - Persistent login state
- Order History - Track previous purchases

📱 Design & UX
- Responsive Design - Works on desktop, tablet, and mobile
- Modern UI - Clean, intuitive interface with smooth animations
- Accessibility - Screen reader friendly with proper ARIA labels
- Performance - Optimized loading and smooth interactions
